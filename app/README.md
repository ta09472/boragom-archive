# 보라곰 플레이스 보관본 소스

React 19, TypeScript, TanStack Router, SEED Design 3, Vite, Biome로 구현한 개인 보관용 정적 화면입니다. `src/data.json`에 수집 자료를 넣어 두었으므로 실행 시 API나 JSON 요청이 필요하지 않습니다. SEED ActionButton을 주요 버튼에 실제 사용하며 CSS 토큰을 함께 번들합니다.

## 다시 빌드하기

Node.js 22.12 이상에서 이 `source` 폴더를 터미널로 열고 실행합니다. 최초 패키지 설치에는 인터넷이 필요합니다.

```sh
npm ci
npm run check
npm run build
```

상위 보관 폴더의 `index.html`과 `assets`만 갱신합니다. `media`, `raw`, `inventory`는 그대로 둡니다. 완성된 `index.html`을 브라우저에서 더블클릭하면 서버 없이 열립니다. 아카이브 폴더 전체를 함께 옮겨야 상대 경로가 유지됩니다.

## 구조

- `src/main.tsx`: 지도 패널, 탭, 메뉴 상세, 방문자/블로그 리뷰, 사진/영상 보기. URL은 해시 라우팅을 사용합니다.
- `src/style.css`: 수집한 원본 화면의 크기/타이포그래피/배치.
- `src/data.json`: 로컬 미디어 경로와 수집 텍스트를 포함하는 빌드용 데이터.
- `prepare-data.mjs`: 상위 `inventory` 및 `raw`에서 데이터를 재생성하고 블로그 HTML의 스크립트/외부 자동 로드/이벤트를 제거합니다. 원본 수집 파일을 바꾼 경우에만 `node prepare-data.mjs` 실행 후 빌드합니다.
- `vite.config.ts`: IIFE 번들, 상대 경로 HTML 생성. 파일 URL에서 모듈 CORS 제약 없이 실행합니다.

지도는 수집한 범위의 캡처를 사용합니다. 이동·확대는 그 범위 안에서 작동하며 길찾기, 실시간 지도 레이어, 계정/리뷰 작성 등 서버 기능은 보관 안내로 연결됩니다. 기존 글과 미디어는 삭제하거나 변형하지 않았고 접근 불가 자료는 수집 목록에 표시합니다. 광고는 다시 로드하지 않습니다.

블로그 HTML은 로컬 미디어로 치환하여 표시합니다. 원문 링크는 명시적으로 클릭했을 때만 외부 브라우징을 하도록 남겼습니다. 재생 가능한 영상에 원문 자막이 제공되지 않아 Biome의 자막 규칙을 예외로 두었고, HTML 삽입은 수집 시 정제한 자료에만 허용합니다.
