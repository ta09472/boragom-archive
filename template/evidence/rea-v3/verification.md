# UI 재현 v3 — 실제 홈 하단 응답·DOM 반영

v2에서 임시로 선택했던 홈 사진과 리뷰를 원본 실행 결과로 대체했다. 원본 관측은 2026-10-29, 네이버 지도 PC 플레이스의 공개 화면에서 수행했다. 보관본의 업체 데이터는 2026-10-28–29 수집본이다. 지도만 정적 캡처이며 패널, 카드, 버튼, 뷰어는 실제 React DOM이다.

## 확정한 데이터와 구조

- 홈 순서: 메뉴 → 클립 → 방문자 사진·영상 → 방문자 리뷰 → 블로그 리뷰. 관련 링크 2개(식신·다이닝코드)도 연결했다.
- 메뉴 4개를 140px 가로 카드로 표시한다. 메뉴 9개 전체는 메뉴 탭에 보관했다.
- 클립 1개는 140×233px 미리보기를 사용하고 클릭 시 보관된 전체 영상을 재생한다. 미리보기의 움직이는 프레임은 캡처 시점에 따라 달라진다.
- 홈 GRID 응답은 10개이며 화면에는 앞 9개가 표시된다. 9개 원본 URL과 기존 고화질 파일을 모두 대응했다. `static-validation.json`, `home-public-network.json`에 ID·순서를 남겼다.
- 원본 홈 방문자 리뷰 요청은 **size 10**, 화면에는 **3개**다. 이전 정적 번들에서 추론한 size 3보다 이번 실제 요청을 우선한다. 리뷰 ID·본문·미디어는 보관 데이터와 일치한다.
- 리뷰 탭 사진·영상 미리보기는 홈 GRID와 별도의 FLAT 응답이다. 원본 응답의 첫 10개 순서로 수정했다.
- 홈 블로그 3개는 원본의 작성자 프로필, 별명, 날짜, 대표 사진, 사진 개수(20·28·23)를 사용한다. 클릭하면 수집된 블로그 전체 본문을 연다.
- 스크롤하면 상단 축약 헤더·탭과 하단 출발/도착/거리뷰/공유/알림받기 행을 유지한다.
- 원본 `visitorReviewMediasTotal`은 462였다. 홈 GRID 응답에는 전체 수나 다음 페이지 커서가 없다. 이 값만으로 462개 전부의 실체를 증명하지 않는다.

## 검증 파일

- `source-home-{top,menu,clip,photos,reviews,blogs}.png`: 원본 1440×764 화면.
- `app-home-{top,menu,clip,photos,reviews,blogs}.png`: 같은 크기의 실제 React 렌더.
- `source-home-*.json`: 해당 원본 DOM·요소 좌표·폰트. 중간 전체 DOM에서 script 태그와 비공개 요청 봉투를 제거했다. 공개 요청만 별도 보존했다.
- `check.log`, `build.log`: TypeScript/Biome 및 프로덕션 빌드 성공.
- `source-checksums.json`: 최종 소스와 번들 해시. `source/src/`에 최신 data.json 및 UI JSON 3개를 포함해 동기화했다.
- `interaction-status.json`: 이 작업자의 클릭 QA는 CDP 포인터 timeout 후 중단했다. 부모 작업자의 p1 최종 런타임 QA는 [app-browser-verification-v3.json](../../inventory/app-browser-verification-v3.json)에 기록했다. 캡처는 p4에서 포인터 없이 DOM 스크롤로 수행했다.

## 비교 해석과 남은 차이

REA 6.7 `compare-web-screenshots`를 실제 원본/보관본 PNG의 검증용 artifact와 함께 실행했다. 임계값은 0이며, 패널 영역은 x=63, y=76, width=390, height=688이다. 각 하단 섹션은 같은 제목 시작 위치로 정렬했다. 전체 화면 비교는 참고용이다. 지도 배경을 과거 원본 캡처로 사용하므로 전체 화면 수치로 UI 동일성을 주장하지 않는다.

수치는 변경된 픽셀 비율과 평균 채널 차이다. **UI 동일률이 아니다.** 글꼴 렌더링, 아이콘, 실시간 영상 프레임, 스크롤바, 광고의 유무도 차이에 포함된다. 원본과 모든 픽셀이 같다고 주장하지 않는다.

- 원본의 동적 광고는 빈 동일 높이 영역으로 보존했다. 다른 가게 추천은 캡처 증거에 남겼지만 보라곰 보관본의 홈에는 재현하지 않았다.
- 원본은 현재 시간에 따라 영업 전/종료 표시가 바뀐다. 보관본은 최초 수집 시점의 영업 종료 문구를 유지한다.
- 실시간 지도 검색·교통·길찾기·거리뷰·알림/로그인은 보관본에서 원래 서버 기능을 실행하지 않는다. 로컬 지도 이동·확대와 안내를 제공한다.
- 리뷰 키워드 펼침, 이미지 확대/다운로드 등 일부 상호작용은 오프라인 보관에 맞게 구현했다. 원본의 모든 팝오버와 서버 상태 전이를 동일하다고 검증하지 않았다.
- 고화질 원본을 작은 카드에 축소한 곳은 네이버의 압축·선명화 프록시 이미지와 픽셀 값이 다를 수 있다. 대표 사진과 홈 블로그 대표 사진은 관측된 표시용 프록시를 별도로 보존했다.
- 사진 탭 전체 혼합 정렬은 대표 사진 우선 배열을 사용한다. 홈 GRID9 및 리뷰 FLAT10은 실제 순서가 검증됐지만 전체 혼합 갤러리의 서버 순서까지 같다고 주장하지 않는다.
- 메뉴·사진·정보 화면은 앞선 원본 관측에 근거해 구현했으며, v3의 수치 비교 범위는 홈과 그 하단 섹션이다. 모바일 원본의 모든 배치 상태까지 픽셀 비교하지 않았다.
- Ego snapshot에서 보인 '예�'는 축약 출력 문제다. 실제 브라우저 DOM의 U+FFFD는 0개였고 블로그 전체 본문에도 해당 문자가 없다.
