# UI 재현 v2 — 구현 완료, 최종 브라우저 검증 대기

홈 상단만 맞추던 구현을 수정하여 홈 전체에 메뉴 → 클립 → 방문자 사진·영상 → 방문자 리뷰 → 블로그 리뷰를 연결했다. 원본에 없던 홈 소식 요약은 제거했다. React DOM으로 구현했으며 전체 화면 캡처를 인터페이스 위에 씌우지 않았다. 지도 배경만 기존 지도 캡처를 유지한다.

## 원본 근거가 있는 변경

- `raw/home-state.json`의 메뉴 preview IDs 4개와 홈 블로그 IDs 3개를 사용한다. 블로그는 223778773681, 223739046970, 223066915610 순서다.
- 원본 배포 코드 `restaurantDetailHomeTabBottom`, module 275505의 컴포넌트 순서에서 클립 module 302836 → 방문자 사진·영상 module 811642 → 방문자 리뷰 module 245842 → 블로그 module 354905가 확인된다. 데이터가 없는 다른 조건부 섹션은 나오지 않는다.
- `place.379`, module 811642는 `getVisitorReviewPhotosForHomeSection`에 `type: "GRID"`를 보내고 `slice(0, h.ex)`를 사용한다. 공통 module 824314의 `ex` 값은 9다. 제목은 “방문자 사진·영상”이다.
- `place.5502`, module 437291은 홈 방문자 리뷰 요청에 `size: 3, includeContent: true`를 사용한다. module 354905는 홈 블로그 목록을 3개로 자른다. 키워드 5개는 module 102237의 `displayCount: 5`다.
- 홈 및 내비게이션의 원본 SVG 경로, 정보 탭의 포장·예약·주차 SVG를 사용했다. 지도 도구 아이콘 9개는 원본 MHTML에 실제 들어 있던 스프라이트에서 읽는다. `assets/ui/`에 출처·해시 manifest를 보관했다.
- 대표 사진 10개는 관측된 원본 `w560_sharpen` 표시용 이미지를 사용한다. 확대·저장은 기존 고화질 파일을 사용한다.
- 메뉴 목록 순서, 104px 섬네일, 메뉴판 하단 배치, 메뉴 상세 경로, 사진 2열 배치, 사진 필터, 확대 화면의 세로 줌 버튼, 정보 소개 말풍선과 편의시설을 수정했다.
- 각 홈 섹션은 보관된 메뉴 상세·영상 플레이어·사진 뷰어·리뷰 탭·블로그 원문으로 연결된다. 전체 목록은 기존 탭에 그대로 남아 있다.

## 아직 원본 화면 확인이 필요한 부분

네이버 CAPTCHA가 나타난 뒤 부모 에이전트의 지시에 따라 TaskSpace 2 브라우저 조작을 중단했다. 다음 항목을 최종 확인 전 “완벽 복제”로 판정하지 않는다.

- [ ] 원본 홈을 아래까지 스크롤한 전체 캡처와 DOM: 실제 표시되는 섹션 순서와 조건
- [ ] 홈 GRID 요청의 9개 사진 ID와 순서: 현재 보관된 방문자 리뷰 사진의 첫 9개로 연결한 임시 선택이며, 홈 GRID 응답과 동일하다고 확인되지 않았다.
- [ ] 홈 size3 요청의 리뷰 ID: 현재 보관된 추천순 리뷰의 첫 3개이며, 홈 요청과 동일하다고 확인되지 않았다.
- [ ] 클립 카드 위치와 크기, 키워드 목록·리뷰·블로그 카드의 실제 홈 치수
- [ ] 최신 빌드 홈 전체와 메뉴·리뷰·사진·정보·사진 뷰어 및 모바일 회귀 검증
- [ ] 사진 기본 갤러리의 전체 혼합 정렬: 관측된 대표사진 우선 순서를 반영했지만 서버의 전체 혼합 순서는 보존 확인이 필요하다.

실시간 광고는 보관 대상 가게 콘텐츠가 아니므로 광고 영역 높이만 유지한다. 실시간 길찾기·위성·거리뷰·계정 쓰기 동작은 오프라인 아카이브의 구현 범위 밖이다.

## 검사와 REA 결과

TypeScript, Biome 검사 및 Vite 빌드가 통과했다. 최신 data.json에는 부모가 복구한 외부 이미지와 본문 텍스트가 들어 있으며 누락 안내는 `data.counts.missing`을 사용한다.

보안 확인 전에 촬영한 **중간 빌드** `app-home.png`의 실제 React 화면과 원본 1440×764 캡처를 REA 6.7로 비교했다. 전체 화면 변경 픽셀 비율 23.8424%, 평균 채널 차이 2.0853/255, 패널(63,76,390,688) 변경 픽셀 비율 42.2663%, 평균 채널 차이 5.1943/255다. 이 숫자는 UI 동일률이 아니며 글꼴·안티앨리어싱 차이도 포함한다. 지도 배경이 원본 캡처이므로 패널 수치를 따로 기록했다.

이 중간 캡처는 홈 하단 추가·최종 지도 스프라이트 수정 이전이다. `comparison-initial.json`, `comparison-panel-initial.json`은 중간 증거일 뿐 최종 검증으로 사용할 수 없다. 최종 비교는 보안 확인 후 수행해야 한다.
